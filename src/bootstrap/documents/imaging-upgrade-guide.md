# Imaging Upgrade Guide

Imaging recommendations should start from installed base and workflow fit. If a practice already runs cloud practice-management software, the seller should emphasize faster setup, centralized image access, and clearer upgrade sequencing.

When the customer wants a compact refresh motion:

- Lead with sensor or scanner upgrades when the practice needs incremental throughput.
- Lead with CBCT only when the clinical story or growth plan justifies higher capital spend.
- Pair imaging with a care plan when uptime risk would otherwise slow adoption.
